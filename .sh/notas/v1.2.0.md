## PDF Enxuto v1.2.0

Compressor, divisor e conversor de PDF **100% local**: nada sai do seu computador. Sem conta, sem nuvem, sem anúncios.

### Novo: Reconhecer texto (OCR)

- Transforma PDFs digitalizados em **PDF pesquisável** (`nome_ocr.pdf`, igual ao original, com texto invisível por cima) e/ou **texto `.txt`**.
- Idiomas: português, inglês, espanhol, francês, alemão e italiano (pode combinar).
- Qualidade da leitura (Rápido, Equilibrado, Preciso), tipo de página, páginas específicas (`1-3, 7`) e opções de imagem do PDF novo (qualidade e cor).
- Botão **Testar** na primeira página: mostra o texto lido e a confiança antes de processar tudo.
- **Tesseract embutido** no pacote do Linux (o pacote cresce cerca de 48 MB). Se não vier embutido, o app usa o do sistema e mostra como instalar.
- Atalhos: `Ctrl+4` abre o OCR e o Histórico passou para `Ctrl+5`.

### Já existente

- **Comprimir** por perfil ou tamanho alvo, mantendo o texto selecionável ou virando imagem.
- **Dividir** por intervalos, a cada N páginas, por tamanho, páginas escolhidas ou marcadores.
- **Converter tabelas em planilha** (XLSX/CSV) com prévia.

### Linux (AppImage)

```bash
chmod +x pdf-enxuto_1.2.0_x86_64.AppImage
./pdf-enxuto_1.2.0_x86_64.AppImage
```

### Windows

Baixe o ZIP, extraia e execute `pdf_enxuto.exe`. O OCR no Windows usa um Tesseract empacotado pelo workflow; se a aba não indicar "embutido no app", instale o Tesseract manualmente.

### Motores opcionais

```bash
sudo apt install ghostscript qpdf
```
