## PDF Enxuto 1.0.2

### Visual sóbrio

- Fim dos degradês: **uma cor de destaque só**, fundo liso e cartões neutros com borda fina.
- Nova cor padrão **Petróleo** — as outras sete (Ardósia, Aço, Oliva, Tijolo, Ameixa,
  Bronze, Índigo) ficam em **Configurações → Aparência**.
- Ícone chapado, sem brilho.
- Texto e ícones sobre a cor de destaque com **contraste calculado** (no tema escuro o botão
  claro ficava com texto branco, quase ilegível).
- Rótulos do seletor segmentado centralizados (estavam colados no topo).
- **Janela sem a moldura do sistema**, com barra de título própria (arrastar, duplo clique
  para maximizar, botões de minimizar/maximizar/fechar) e bordas redimensionáveis pelo app.

### Compressão em duas abas

- **Perfis prontos** *ou* **Tamanho alvo** — nunca os dois ao mesmo tempo.
- No modo tamanho alvo a busca começa na melhor qualidade e desce (resolução e JPEG) até
  caber no alvo ou até o piso de qualidade. A tela mostra a faixa exata da busca
  (ex.: 300 dpi / JPEG 92 → 152 dpi / JPEG 52).
- Aviso claro quando o motor escolhido não consegue mirar o alvo (qpdf ou motor nativo com
  "manter texto").
- Alvo por arquivo ou para o conjunto (a cota é distribuída proporcionalmente).

### Outros

- **Fechar encerra na hora**, sem janela de confirmação.
- Tamanho, posição, tamanho mínimo e título da janela agora são aplicados corretamente no
  Linux (antes eram ignorados e a janela abria no tamanho padrão do Flutter).
- Limpeza automática das pastas temporárias deixadas por execuções interrompidas.
- 43 testes automatizados, incluindo verificação visual do layout.

### Instalação

**Linux**

```bash
sudo dpkg -i pdf-enxuto_1.0.2_amd64.deb
sudo apt-get install -f   # se faltar alguma dependência
```

**Windows**

Baixe o ZIP, extraia e execute `pdf_enxuto.exe` — não precisa instalar.

### Motores opcionais

O app já funciona sem instalar nada. Se quiser resultados ainda melhores:

```bash
sudo apt install ghostscript qpdf
```
